# Eagleman Campaign — The Mathematics of Distributed Decision-Making

A staged research program testing ErisML-Lib's interaction measurements
(order sensitivity, context dependence, higher-order composition,
temporal structure, distributed contribution, internal-state
invariance) against **human** cognitive dynamics — with David Eagleman
(Stanford / Center for Science and Law) as the prospective
neuroscience conversation partner.

**Source brief:** `source/ErisML_Eagleman_Research_Campaign_10of10.docx`
— prepared by Kim Baley (Justice Innovations), 2026-08-22. The
markdown documents in this directory are the working refactor of that
brief into the repo's campaign regime; the docx remains the archival
source.

**Scope:** ErisML-Lib only. Related repositories (erisml-compiler,
non-abelian-sqnd, sqnd-probe, …) are intentionally out of scope; if
later included, their evidence must be audited separately.
