# Reply to the IEEE AQ2 follow-up query (2026-10-19)

The query came by email from IEEE production on 2026-10-19. It said that the AQ2 answer of
2026-10-15 left the tables out of sequence, because "Table VII" is cited at proof line 327,
before Tables III to VI.

## Diagnosis (from the proof text, `TCSS-2026-03-0366_proof-for-review.pdf`)

First citation of each table in the running text, by proof margin line:

| Line | Cites | Text |
|---|---|---|
| 208 | Table I | "The nine dimensions in Table I ..." |
| 263 | Table II | "Table II counts Tbase and Tα ..." |
| 326–327 | **Table VII** | "... [28], which reproduces every number in Table VII." |
| 327 | Table IV | "Table IV collects the coordinates." |
| 334–335 | Table III | "The mechanisms in Table III are therefore treated as ..." |
| 539 | Table V | |
| 641 | Table VI | |
| 666 | Table VII | "Table VII presents the complete sixteen-target results." |
| later | Tables VIII, IX, X | in order |

(Table II's own body also cites Table IV, in the row "Coordinate constants of Table IV".)

The 2026-10-15 answer fixed only the III/IV inversion. The sentence at lines 326–327 is a
forward reference to the results table, and it is the only other break. Rewording it removes
the break, and Tables V to X keep their numbers. Table VII sits in Section VI-B ("Complete
Results"), so the reworded sentence keeps its meaning. Figures 1 to 5 are already cited in
order.
