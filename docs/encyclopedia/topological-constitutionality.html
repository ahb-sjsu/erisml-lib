Topological constitutionality result

DefinitionThe constitutional subcomplex is the part of the judicial complex whose vertices and simplices satisfy every constitutional predicate. A statute is called constitutional if and only if adding it leaves all path homology groups of that subcomplex unchanged, which the volume restates as creating no new non-trivial directed cycle.
ExampleIn the volume’s running example the Digital Privacy Act adds two edges that create two new non-trivial directed cycles in the constitutional subcomplex, so the first path homology group changes and the statute is ruled unconstitutional.
VolumeGeometric Law, Volume 5 of the Geometric Series; entry id topological-constitutionality, kind result.
StatusA conditional theorem with a proof sketch, whose if-and-only-if form the chapter also poses as a conjecture. The volume's applications of it are worked examples and not computations on a case corpus. Corrections: none recorded.
Defining equationnone
Assumptions and scope
  • The front matter classes the use of path homology for constitutionality as a modeling axiom. The theorem has a proof sketch.
  • The same chapter states completeness as a conjecture. If the conjecture is false, preserved path homology is a necessary condition and not a sufficient one, and the appendix’s full statement claims three one-directional parts only.
  • Building the subcomplex requires deciding which vertices satisfy each predicate and how a statute changes the graph. The volume says this legal judgment cannot be fully automated.
  • For a finite directed graph the groups are computable by Smith normal form of the boundary matrices. Chapter 16 leaves open whether the fundamental group detects inconsistencies that path homology misses.
Prior artPath homology of directed graphs, which the volume attributes to Grigor'yan, Lin, Muranov and Yau.
