Basin of attraction of a reasoning minimum concept

DefinitionThe set of states from which gradient flow on the evaluation function converges to a given local minimum. Its depth is the lowest value of the function on the basin's boundary minus the value at the minimum. A dead zone is different. It is a flat region with a near-zero gradient and no minimum.
ExampleFor the function (x^2 - 1)^2 on the line, the minima are at -1 and 1, the basin of 1 is every x above 0, and its depth is the value 1 at x = 0 minus the value 0 at x = 1.

Assumptions and scope
  • It assumes a smooth evaluation function with isolated local minima on a Riemannian reasoning manifold. The basins then partition the manifold up to a set of measure zero.
  • The definition is standard dynamics. That a model’s premature convergence is a trajectory settling in such a basin is the volume’s posited reading.
