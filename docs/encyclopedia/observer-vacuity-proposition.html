vacuity proposition for the cognitive observer result

DefinitionA cognitive observer is a representation map, a metric, a budget and an admissible set, together with a search policy. If all four components are fitted to a finite choice record, some observer reproduces any record exactly, so choice data alone cannot disconfirm the account.
ExampleSuppose an agent picks a from the menu {a, b} and b from the menu {a, b, c}. Setting the admissible set to {a} on the first menu and {b} on the second reproduces the record under any metric and budget, so the fit excludes nothing.

Assumptions and scope
  • The paper marks the proposition proved, elementary and not new. Making the admissible set menu-dependent and equal to the option chosen reproduces any record.
  • The account has content under modular identification, where each component is estimated from evidence disjoint from the record it predicts. It then excludes records that differ from the induced order by more than the budget’s indifference band (ledger row GC-28).
  • How much a single unidentified component can absorb is open (GC-33), so identifying three of four components is not known to beat identifying none.
  • The paper is draft 0.1.
Prior artThe paper places it beside the result of Kalai, Rubinstein and Spiegler that rationalization by multiple rationales admits every choice function, and contrasts it with Afriat's theorem.
