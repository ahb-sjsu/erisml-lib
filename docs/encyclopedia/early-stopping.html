early stopping instrument

DefinitionHalting a boosting run when a held-out score stops improving. The rule reads the held-out fold, so it is a harness and the round count is a fitted parameter. Chapter 7 section 7.5. Also early-stopping.
ExampleBoosting for 200 rounds and keeping round 45, where the held-out score peaked, makes 45 a fitted parameter.
BookData Mining as Observation, draft 0.2, commit a0db6a8; entry id early-stopping, kind instrument.
Statusno ledger row names this entry. Corrections: none recorded.
Defining equationnone
Assumptions and scope
  • Halting a boosting or gradient run when a held-out score stops improving. The stopping rule reads the held-out fold, so the fold it reads is no longer held out for the reported score, and a scorer that has read the test fold scores it perfectly.
  • Early stopping is a harness. The round count it picks is a fitted parameter, and the report states which fold picked it and which fold scored it.
