Scalar Irrecoverability Theorem result

DefinitionAny continuous map Q from the nine-dimensional moral attribute vector to one scalar is not injective, has no function that recovers the vector from the scalar, and in general gives a scalar-optimal path that differs from the geodesic on the full manifold by an amount no function of Q alone bounds.
ExampleLet Q be the sum of the nine coordinates. The states (1, 0, 0, 0, 0, 0, 0, 0, 0) and (0, 1, 0, 0, 0, 0, 0, 0, 0) both map to 1, so no function of the value 1 can return both. The directions Q cannot see number 9 - 1 = 8.

Assumptions and scope
  • Q must be continuous, and continuously differentiable where the proof uses its differential (corrected in v1.25). At a regular point the kernel of the differential has dimension at least 8.
  • Part (iii) is stated in general. It does not say that every scalar rule gives a worse path in every case.
