Geodesic deviation of a reasoning trajectory concept

DefinitionThe cost of a reasoning trajectory minus the cost of the geodesic that joins the same endpoints. The optimal trajectory is the path from the problem state to the goal region that minimizes the cost functional. The deviation is never negative and is zero only for a geodesic.
ExampleIn the volume’s illustrative triage example the geodesic costs about 2.1 nats and the corrupted trajectory about 4.6 nats, so the deviation is 4.6 - 2.1 = 2.5 nats.

Assumptions and scope

  • It measures the efficiency of the path and not whether the answer is right. A lucky shortcut can be accurate and still have a large deviation.
