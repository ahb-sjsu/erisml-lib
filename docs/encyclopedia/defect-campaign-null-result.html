defect campaign, the recorded run correction

DefinitionThe recorded run of the defect-prediction campaign did not recover the generator's structure. The best configuration contains the OO group, which the generator makes pure noise, and won on one correct positive prediction. The robustness index was exactly zero because the evaluation function reads only whether each parameter is below 1000.
ExampleA configuration that finds no defective module misses the precision, recall and F1 targets by 70, 65 and 67 points, so its mean absolute error over the five targets is at least (70 + 65 + 67)/5 = 40.4. The numbers are from the volume’s recorded run.
VolumeGeometric Methods, Volume 1 of the Geometric Series; entry id defect-campaign-null-result, kind correction.

Assumptions and scope
  • An earlier version of the chapter printed typical output that no run had produced and reported that the analysis recovered the generator’s structure. The recorded output differs from it in almost every respect.
  • The targets cannot be met on these data. The generator’s own formula, used as an oracle, reaches an AUC of 54.5% against a target of 80%, and the 31 configurations span 43% to 59%, within two standard errors of chance.
  • Over 20 redraws of the same generator 15 different configurations win, so the choice of best configuration carries no information about the generator.
  • The run is exploratory. No prediction was registered before it.
