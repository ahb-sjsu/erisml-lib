The read distortion identity. The expected quadratic form of an error under a read operator equals the trace of the operator times the error's second-moment matrix $M_\delta$, and for the identity reader it is the trace of that matrix, which is mean squared error. No symmetry of the operator and no centering are needed. The operator is fixed in the statement, so this is the linear case, and chapter 0 says when the averaged form is a surrogate.Equation 0.10ReadDistortion.lean, read_distortion, identity_reader

The Monotone Invariance Theorem. A strictly increasing transform of a score leaves its AUROC, defined pairwise with ties counted one half, unchanged (auroc_comp, hypothesis StrictMono); a strictly monotone transform in either direction leaves its optimal thresholded F1, defined by sweeping the threshold over every score value in both directions, unchanged (optF1_comp). What the check does not cover is stated as plainly. The flip theorem and the anti-arm bound are about the two-dimensional diagonal case the chapter draws. The read operator file takes the sensitivities as given vectors, so it checks the algebra of the average and not the differentiation that produces them, and the probe file's consumers are affine, which is the case in which a central difference is exact. The family-wise error assumes independent looks. The Youden ceiling is checked at one operating point, and the ceiling over the sweep is the supremum of that bound, as equation 5.4 states. The alignment and coupling null are checked for diagonal operators in two dimensions. The hubness file checks the counting identity behind the Poisson mean, and the Poisson ceiling file checks that the tail is monotone in the count, not the value of the tail itself. The rank certificate file checks the per-pair fact under a bounded ratio and not the floors of equation 11.2, which are derived in the source from the ratio's concentration. The vacuity file checks that the bar is monotone in the candidate count and what the ratio means, not the expected maximum of a normal sample. The ledger rule is checked as the book states it, and the seal and leakage files check what a hash and an identifier can and cannot establish. The water-filling file checks the two-direction case and the equal-distortion property, not the optimality of the allocation over many directions. The distance concentration file checks the algebra of the relative spread under the independence model, not that real data obey the model. The deployment mismatch file checks that a weighted mean lies between its extremes, which is the whole of what a benchmark drawn from one slice can be held to. The intrinsic dimension file checks the algebra that turns a power law into a dimension, not Weyl's law itself, which is an asymptotic statement about manifolds. The two fairness files check the arithmetic of rates and ratios, and the multiple comparisons file assumes independent tests, as the Bonferroni file does. The Landauer file checks the constant and the monotonicity of the bound, and the entropies in equation 13.3 are the ledger's measurements. The whitening and Mahalanobis files work in the covariance's eigenbasis, where the covariance is diagonal, which is the form equations 0.6 and 10.1 state. The standard error file assumes independent draws, which is the assumption the Nadeau and Bengio file removes. The attention file takes scalar values and one head, and the product quantization file checks two pieces, which is the case the additivity extends from. The Laplacian file states the unnormalized form, and equation 0.19's normalized form is the same quadratic form in rescaled coordinates. The eviction file checks what attention over a subset can and cannot do, and the serving-stack numbers are the ledger's. The pipeline file's rank bound is for linear stages, and the quotient inheritance holds for every stage. The teacher forcing file takes the model as a function of the prefix, which is what a decoder is. The geodesic distance file takes the distance from Mathlib's simple graphs, and the radius-and-angle claim of chapter 3 stays a measurement, as does the radius-against-degree correlation. The eigenvalue file states the two facts the book uses and not the spectral theorem, which Mathlib holds and the book does not restate. The classifier, boundary, and margin files are for the linear classifier, and the null model file checks what a label permutation preserves, not the distribution of any statistic under it. The confound file is the linear case, and the block error file assumes independent symbol losses. The cache file counts hits over a request set and says nothing about replacement policies. The contrastive file uses a margin loss on pair scores, and the paraphrase file takes the within-input spread as given. The quantizer files bound the identity reader's error, and what a quantizer does to a consumer is the flip's question. The rotary file is the two-dimensional rotation the embedding is built from, and the cross-validation file checks the accounting of folds and not their independence, which is the correction's subject. The principal-components file works in the eigenbasis and does not prove that the eigenbasis exists, which is the spectral theorem. The commute-time file states the collapsed resistance and its consequences and not the convergence to it, which is von Luxburg, Radl, and Hein's theorem. The multiplet file pairs the cycle's eigenvalue formula and does not derive the formula from the cycle's Laplacian. The classifier and clustering files state the arithmetic each method rests on, the stump's flatness, the sigmoid's shape, the mean's optimality, the linkage updates, and not that any method finds what it is looking for. The boosting file checks one reweighting step and not the convergence of the sum, and the shard file assumes the global top set is strict. The bar file states the logic of a registered bar against a null and not any statistic's distribution, the rank file takes Mathlib's rank and does not compute one, and the percentile file states the empirical distribution function and not any order statistic. The twelve-domain flip of chapter 4 is a measurement, not a theorem, and stays in the ledger as demonstrated. AUROC and F1 are formalized on finite index sets with real scores, which is the case every chapter uses. The remaining results the book cites as proved, the Keep-the-Angle theorem among them, are proved in Volume 14 and are not re-checked here.
